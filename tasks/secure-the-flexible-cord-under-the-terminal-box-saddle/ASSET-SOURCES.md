# Station asset sources and license scope

The task folder contains procedural task geometry and no copied robot meshes, table textures or camera assets. The imported YAM robot model is supplied by the runtime from [i2rt](https://github.com/i2rt-robotics/i2rt), source commit `120c3c81400171174604e503943f8d1ebc891058`, with its `LICENSE.i2rt` MIT notice. Table, floor, lights and camera housings are procedural runtime station primitives; camera/arm calibration is the runtime's Dream/YAM station calibration derived from ARISE-Initiative/yamlab commit `ec0455d2`. The installed yam_arena README reports that its wrapper, ported from [YAM-inspect-Isaac](https://github.com/ttpierson/YAM-inspect-Isaac), has no repository license yet. That runtime code/calibration is an external dependency, not licensed or redistributed by this task. Task-authored code is MIT and task documentation CC BY 4.0; those notices do not grant rights to the external wrapper. No maker CAD, photographs or textures are included.
